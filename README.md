# 桌面天文机械表

## 怎么用

**直接双击 `dist\桌面天文机械表.exe`** —— 单文件，无需安装 Python，不会闪 cmd 窗口。

其他入口：

| 文件 | 用途 |
|---|---|
| `dist\桌面天文机械表.exe` | **推荐**，双击即用 |
| `启动天文钟.bat` | 优先启动 exe；没有 exe 时回退用 pythonw 跑源码 |
| `桌面天文机械表.pyw` | 改了源码后双击预览（.pyw 不走控制台，无黑窗口） |

> 不要直接双击 `astronomical_clock.py`。Windows 把 `.py` 关联到 `python.exe`
> （控制台程序），双击会先闪一个黑窗口，这是系统行为，与程序本身无关。

## 操作

- **左键拖动**：移动窗口
- **右下角拖动**：缩放尺寸
- **双击**：切换窗口置顶
- **右键**：菜单（表盘样式 / 尺寸 / 置顶 / 隐藏 / 经纬度 / 关于 / 退出）
- **托盘图标左键**：显示 / 隐藏切换
- **托盘图标右键**：与表盘右键完全相同的菜单

托盘图标首次启动可能被 Windows 收进任务栏的 `^` 折叠区，
展开后把它拖到常显区即可长期可见。

## 关于数据

日月位置、节气、昼夜长短、月相全部按**真实天文算法**实时计算：

- 太阳 / 月亮视黄经 → 二十四节气、黄道十二宫
- 太阳赤纬 + 本地纬度 → 昼长、日出日落（驱动外圈昼夜弧）
- 日月黄经差 → 月相
- 本地恒星时 → 恒星时环

经纬度在托盘/表盘右键 → 设置经纬度里改，首次启动会自动定位。

## 重新打包

```bash
python tools/make_icon.py                    # 生成 app.ico
python -m PyInstaller build.spec --noconfirm --clean
```

产物在 `dist\桌面天文机械表.exe`。`console=False` 是"不弹 cmd 窗口"的关键，
已通过 PE 头校验（Subsystem = 2 / WINDOWS_GUI）。

`tools/` 下另有两个效果预览脚本（候选样式、外圈动效），仅开发时用。

## 文件说明

| 文件 | 说明 |
|---|---|
| `astronomical_clock.py` | 主程序，全部逻辑 |
| `app.ico` | 程序图标，含 16/24/32/48/64/128/256 多尺寸分别绘制 |
| `build.spec` | PyInstaller 打包配置 |
| `tools/make_icon.py` | 图标生成脚本（按尺寸分级简化笔画） |
