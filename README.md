# 桌面天文机械表

纯 PyQt6 自绘的高仿真机械表盘。六套内置主题、严格啮合齿轮系、陀飞轮，日月位置与节气月相均按真实天文算法实时计算；另可选用自己的图片作为第七套「自定义背景图片」表盘。

## 下载即用

不想装 Python 的话，直接到 [Releases](https://github.com/fdsuf/astronomical-clock/releases)
下载最新版 `AstronomicalClock-v2.0.0-win64.exe`，双击运行。

## 从源码运行

```bash
pip install PyQt6
```

然后双击 `桌面天文机械表.pyw`（`.pyw` 不走控制台，不会闪黑窗口）。

自己打包 exe：

```bash
python tools/make_icon.py
python -m PyInstaller build.spec --noconfirm --clean
```

产物在 `dist\桌面天文机械表.exe`。

## 怎么用

**双击 exe** 即可 —— 单文件，无需安装 Python，不会闪 cmd 窗口。

其他入口：

| 文件 | 用途 |
|---|---|
| `dist\桌面天文机械表.exe` | **推荐**，双击即用 |
| `启动天文钟.bat` | 优先启动 exe；没有 exe 时回退用 pythonw 跑源码 |
| `桌面天文机械表.pyw` | 改了源码后双击预览（.pyw 不走控制台，无黑窗口） |

> 不要直接双击 `astronomical_clock.py`。Windows 把 `.py` 关联到 `python.exe`
> （控制台程序），双击会先闪一个黑窗口，这是系统行为，与程序本身无关。

## 操作

- **左键拖动**：移动窗口
- **右下角拖动**：缩放尺寸（100～900 px 自由调节）
- **Ctrl + 鼠标滚轮**：自由缩放尺寸（上滚放大 / 下滚缩小，每格 20 px；大小无档位限制）
- **双击**：切换窗口置顶
- **拖到屏幕上/左/右边缘后松手**：缩成 96×96 小表（拖动过程中不缩，松手才判定）；鼠标移上去放大回原尺寸、移开又缩回；拖离边缘松手后恢复原尺寸（原尺寸不受影响，重启仍是你在菜单里设定的大小）。放大/缩小带 260ms 平滑过渡动画，动画期间不会误判悬停
- **右键**：菜单（表盘样式 / 自定义背景图片 / 调整背景焦点 / 恢复默认背景 / 尺寸 / 窗口置顶 / 开机自启动 / 隐藏 / 经纬度 / 关于 / 退出）
  - 「表盘样式」新增第七种 **自定义背景图片**：选一张本地图片后，按圆形裁剪铺底，并叠加刻度、指针、节气/星座、日出日落与恒星时
  - 选图后会弹出 **背景区域选择框**：预览始终完整显示原图，一个正方形方框圈住要显示的区域；用鼠标**拖动方框**移动位置，框内画面即最终显示区域，主体偏离图片中心时也能正确保留
  - **滚轮直接放大 / 缩小选择框**：选区占图片短边的 20%～100%，每格 15%，到上下限后继续滚动不再变化，不会无限缩放。框越大显示的原图范围越大，框越小选区越精细；缩放时鼠标指向的画面位置保持不动。图片本身不缩放、无需滚动查看；取消则放弃本次选图
  - 「调整背景焦点…」可对已设置的背景重新拖动 / 缩放选择框，即时生效；选区位置与大小都会持久化，重启后保持
  - 图片会复制到 `%APPDATA%\AstroClock\backgrounds\`，设置里只保存副本路径与焦点；原图移动或删除不影响显示
  - 「恢复默认背景」停止使用图片并切回默认表盘 **高仿真机械表**；不再引用的图片副本会被自动清理（只清理由本程序生成的 `bg_*` 文件，目录里其它文件不受影响）
  - 「尺寸」子菜单顶部有操作说明，并实时显示当前尺寸；下方 280/340/400/500/600 是快捷档位，Ctrl+滚轮可调到任意大小
  - **吸附为小表 / 悬停放大期间**：表盘右键、Ctrl+滚轮、菜单里的尺寸档位均不可用；此时展开「尺寸」子菜单会看到「先放大时钟，再调整尺寸」的提示（档位已置灰）。先拖离边缘松手、恢复成固定窗口后再操作。托盘右键始终可用，但同样不能在此状态下改尺寸
- **托盘图标左键**：显示 / 隐藏切换
- **托盘图标右键**：与表盘右键完全相同的菜单（含吸附/悬停期间）

### 开机自启动

右键菜单 → **开机自启动**，勾选后写入注册表
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\AstroClock`，
随 Windows 登录自动运行，无需管理员权限。

- 打包版写入 exe 完整路径；源码版写入 `pythonw.exe + 脚本路径`，均整段加引号，中文/空格路径可用
- 取消勾选即删除注册表项，不留僵尸启动项
- 菜单状态**实时读注册表**：若在任务管理器「启动」标签里禁用了程序，菜单会如实显示未勾选；
  重新在程序里勾选会同时清除任务管理器的禁用标记
- 开机启动不会弹 cmd 黑窗（打包为 GUI 子系统 / 源码走 pythonw）

托盘图标首次启动可能被 Windows 收进任务栏的 `^` 折叠区，
展开后把它拖到常显区即可长期可见。

## 关于数据

日月位置、节气、昼夜长短、月相全部按**真实天文算法**实时计算：

- 太阳 / 月亮视黄经 → 二十四节气、黄道十二宫
- 太阳赤纬 + 本地纬度 → 昼长、日出日落（驱动外圈昼夜弧）
- 日月黄经差 → 月相
- 本地恒星时 → 恒星时环

经纬度在托盘/表盘右键 → 设置经纬度里改，首次启动会自动定位。

## 自定义背景图片

1. 表盘/托盘右键 → **自定义背景图片…**
2. 选择 JPG / PNG / WebP / BMP 图片
3. 在 **背景区域选择框** 里拖动方框移到主体位置；滚动鼠标滚轮放大 / 缩小方框（选区 20%～100%，有上下限，框内就是表盘最终显示的画面）；点「确定」完成，点「取消」放弃本次选图
4. 程序把图片复制到 `%APPDATA%\AstroClock\backgrounds\`，按所选区域裁剪并切换到新表盘
5. 以后重启会按保存的选区自动加载副本；即使原图被移动或删除也不受影响
6. 想换区域：右键 → **调整背景焦点…**，重新拖动 / 缩放方框即可
7. 想恢复内置盘面：右键 → **恢复默认背景**，会切回高仿真机械表，不再用的副本会被自动清理

> 背景图片只解码/缩放一次并缓存，绘制时按圆形裁剪，不逐帧读文件。选区位置以比例（0~1）保存、大小以占短边比例 `bg_crop_ratio` 保存（旧版 `bg_zoom` 会自动迁移），默认居中且选满短边；重启后仍按同样的区域裁剪。

## 重新打包

```bash
python tools/make_icon.py                    # 生成 app.ico
python -m PyInstaller build.spec --noconfirm --clean
```

产物在 `dist\桌面天文机械表.exe`。`console=False` 是"不弹 cmd 窗口"的关键，
已通过 PE 头校验（Subsystem = 2 / WINDOWS_GUI）。

`tools/` 下另有两个效果预览脚本（候选样式、外圈动效），仅开发时用。

## 文件说明

| 文件 | 说明 |
|---|---|
| `astronomical_clock.py` | 主程序，全部逻辑 |
| `app.ico` | 程序图标，含 16/24/32/48/64/128/256 多尺寸分别绘制 |
| `build.spec` | PyInstaller 打包配置 |
| `tools/make_icon.py` | 图标生成脚本（按尺寸分级简化笔画） |
